# Drishti AI

Drishti AI checks whether an image, video or piece of text has been edited or generated by AI. It runs a set of forensic detectors, combines their scores into one verdict, and explains the result in plain language.

Everything runs locally: the detectors are plain signal processing, and the two ML models are downloaded once from Hugging Face.

## What it checks

**Images** (`image_module/`) — 15 detectors, each returning a 0–1 score:

| Detector | What it looks for |
|---|---|
| Error Level Analysis (ELA) | Regions saved at a different JPEG quality than the rest |
| CFA artifacts | The colour-filter pattern a real camera sensor leaves behind |
| Compression anomaly | Breaks in the 8×8 JPEG block grid |
| Noise, median filter, wavelet stats | Smoothing and noise that don't match a real photo |
| Frequency, histogram kurtosis | Statistical patterns typical of diffusion models |
| Luminance gradient, reflection integrity | Lighting and eye reflections that don't match the scene |
| Geometric symmetry, face boundary blend | Impossible symmetry, face-swap seams along the jaw |
| Patch / copy-move, adversarial noise, EXIF | Copied regions, hidden noise, missing or edited metadata |

Two Hugging Face image classifiers (`dima806/deepfake_vs_real_image_detection`, `Organika/sdxl-detector`) add an ML opinion.

**Video** (`video_module/`) — blink rate, facial landmark jitter, optical-flow consistency, heartbeat signal in skin colour (rPPG), temporal noise and spectral fingerprints across frames.

**Text** (`text_module/`) — word repetition and sentence-complexity heuristics for AI-written text, plus an optional web search for copied text (needs a Serper API key).

## How the verdict is made

`image_module/decision_engine.py` combines the detector scores with weighted voting. Signals that are hardest to fake (sensor patterns, compression, ELA) carry the most weight. A webcam mode lowers the weight of detectors that normal webcam grain tends to trigger, to cut false alarms on live camera frames.

A built-in assistant ("Detective Drishti") answers questions about the result and explains each forensic term, without calling any cloud API.

## Tech stack

Python · Django · OpenCV · NumPy / SciPy · PyWavelets · PyTorch · Hugging Face Transformers

## Run it locally

```bash
git clone https://github.com/Ganesh-pixel-dev/drishti_ai.git
cd drishti_ai
python -m venv venv
venv\Scripts\activate          # macOS/Linux: source venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Open http://127.0.0.1:8000. The first image check downloads the two ML models, so it takes longer.

Optional: create a `.env` file with `SERPER_API_KEY=...` to turn on the copied-text web search.

## Limits

- A research and learning project, not a certified forensic tool. Treat its verdict as a signal, not proof.
- Detector weights were tuned by hand, not on a labelled benchmark.
- Settings are for local development only (`DEBUG = True`).
